# Examples

## Stable Release

```json
{
  "major":1,
  "minor":0,
  "patch":0
}
```

## Minor Update

```json
{
  "major":1,
  "minor":3,
  "patch":0
}
```

## Patch Release

```json
{
  "major":1,
  "minor":3,
  "patch":5
}
```

## Pre-release

```json
{
  "major":2,
  "minor":0,
  "patch":0,
  "prerelease":"beta.1"
}
```

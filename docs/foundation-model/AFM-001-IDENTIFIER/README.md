# AFM-001 — Identifier

## Overview

The Identifier specification defines the canonical identity model used across the Atlas ecosystem.

Every object defined by Atlas MUST possess an Identifier.

This specification is the foundation upon which all higher-level models are built.

---

# Purpose

Provide a globally unique, immutable, implementation-independent identity model.

---

# Applies To

This specification applies to:

- Entity
- Relationship
- Event
- Contract
- Node
- Registry Record
- Capability
- Metadata Objects

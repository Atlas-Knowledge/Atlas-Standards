# AIM-002 — Entity

## Overview

Entity represents a concrete Resource with an independent identity and lifecycle.

An Entity models something that exists independently within the Atlas information space.

---

## Purpose

The Entity model specializes Resource by defining persistent information objects.

---

## Scope

Examples include:

- User
- Organization
- Repository
- Specification
- Standard
- Service
- Dataset
- AI Model

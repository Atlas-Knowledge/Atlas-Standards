# AEM-001 — Execution Kernel

## Overview

The Execution Kernel is the central execution coordination model of Atlas.

It defines the minimum execution responsibilities required by every Atlas implementation.

The Kernel coordinates execution but does not own business logic.

---

## Purpose

Defines:

- Execution lifecycle
- Service coordination
- Resource orchestration
- Capability discovery
- Execution boundaries

# Atlas Traceability Matrix

## Overview

This document maps Atlas Specifications to their corresponding Atlas Standards.

---

| Specification | Standard(s) |
|---------------|-------------|
| ASF-0001 | CAN-001, CAN-002 |
| ACCS-0001 | AFM-001, AFM-002, ACM-001, ACM-005 |
| AKS-0001 | AIM-001, AIM-002, AIM-003 |
| AES-0001 | AEM-001, AEM-002 |
| ARS-0001 | AEM-003, CTS-003 |
| AVS-0001 | CTS-001, CTS-002 |
| ADS-0001 | AIM-010 |
| AMS-0001 | ACM-005 |
| AIS-0001 | STD-001 |

---

## Purpose

The Traceability Matrix ensures that every Atlas Specification can be traced to one or more implementation standards.

---

## Guiding Principle

> Every normative specification SHOULD be implemented through one or more Atlas Standards.

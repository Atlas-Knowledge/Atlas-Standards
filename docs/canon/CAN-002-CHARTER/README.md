# CAN-002 — Atlas Charter

## Overview

The Atlas Charter defines the governance structure, responsibilities, and decision-making processes of the Atlas Standards project.

It establishes how standards are proposed, reviewed, approved, published, maintained, and retired.

The Charter complements the Atlas Constitution and serves as the operational framework for the Atlas Standards Organization.

---

## Purpose

The Charter defines:

- Organizational structure
- Roles and responsibilities
- Working Groups
- Decision process
- Publication process
- Standard lifecycle

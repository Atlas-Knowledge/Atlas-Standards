# CAN-005 — Atlas Design Philosophy

## Overview

The Atlas Design Philosophy defines the engineering mindset that guides every decision within the Atlas ecosystem.

Unlike architecture or standards, this document explains *how engineering decisions should be made*.

---

## Purpose

This package defines:

- Engineering philosophy
- Design priorities
- Decision criteria
- Long-term architectural direction

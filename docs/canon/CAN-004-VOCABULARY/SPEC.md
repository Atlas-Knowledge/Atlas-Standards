# Atlas Vocabulary

> This document is **Normative**.

---

# Purpose

This document defines the official vocabulary of Atlas.

Every Atlas specification SHALL use these definitions consistently.

No specification SHALL redefine a canonical term.

---

# Canonical Terms

## Atlas

The complete standards ecosystem, including Canon, Models, Standards, Policies, Conformance, and Reference Implementations.

---

## Canon

The permanent engineering foundation defining the identity, philosophy, and governance of Atlas.

---

## Core Model

The abstract concepts upon which Atlas is built.

Examples:

- Identity
- Version
- Time
- State

---

## Information Model

Defines how knowledge is represented.

Examples:

- Entity
- Relationship
- Event
- Contract

---

## Platform Model

Defines the execution architecture of Atlas.

Examples:

- Kernel
- Runtime
- Registry
- Storage

---

## Standard

A normative document defining a concrete representation or protocol.

Examples:

- UUID
- JSON
- ISO 8601
- Semantic Versioning

---

## Policy

A mandatory operational or governance rule.

Policies define required behavior rather than data models.

---

## Conformance

The process of verifying compliance with Atlas standards.

---

## Reference Implementation

An implementation intended to demonstrate correct application of Atlas standards.

Reference implementations are informative unless explicitly declared otherwise.

---

## Working Group

A group responsible for maintaining a specific area of Atlas.

---

## Proposal

A suggested change that has not yet been approved.

---

## Draft

A work in progress.

Normative content may change.

---

## Stable

A specification approved for production use.

---

## Deprecated

A specification that remains valid but is scheduled for removal.

---

## Archived

A specification that is no longer maintained.

---

# Reserved Terms

The following names are reserved:

- Atlas
- Canon
- Core Model
- Information Model
- Platform Model
- Atlas Compatible
- Atlas Certified
- Atlas Standards

Implementations SHALL NOT redefine these terms.

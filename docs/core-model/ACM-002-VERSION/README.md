# ACM-002 — Version

## Overview

Version is the canonical concept representing the evolution of an Atlas artifact over time.

Version describes revision history independently of any concrete versioning scheme.

---

## Purpose

This specification defines:

- Version semantics
- Version lifecycle
- Version compatibility
- Version independence

# ACM-003 — Time

## Overview

Time is the canonical temporal concept used throughout the Atlas ecosystem.

This specification defines the abstract concept of time independently of any concrete representation.

---

## Purpose

This specification defines:

- Temporal concepts
- Temporal ordering
- Temporal validity
- Time independence

# ACM-006 — Reference

## Overview

Reference defines the canonical mechanism for referring to another Atlas object without becoming that object.

References enable interoperability while preserving object independence.

---

## Purpose

This specification defines:

- Reference semantics
- Reference integrity
- Reference validation
- Reference independence

---

## Scope

Applies to every Atlas object capable of referring to another Atlas object.

# ACM-004 — State

## Overview

State represents the current condition of an Atlas object during its lifecycle.

This specification defines the abstract concept of state independently of any implementation-specific workflow.

---

## Purpose

This specification defines:

- State semantics
- State transitions
- State validation
- State independence

---

## Scope

Applies to:

- Entities
- Relationships
- Contracts
- Events
- Runtime Components
- Registries
- Specifications

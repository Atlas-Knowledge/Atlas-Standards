# ACM-005 — Metadata

## Overview

Metadata represents structured descriptive information associated with an Atlas object.

Metadata enables discovery, interoperability, governance, validation, and lifecycle management.

---

## Purpose

This specification defines:

- Metadata semantics
- Metadata ownership
- Metadata evolution
- Metadata validation

---

## Scope

Applies to every Atlas object.

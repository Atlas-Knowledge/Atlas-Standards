# ACM-001 — Identity

## Overview

Identity is the fundamental concept upon which all Atlas objects are built.

Every object represented within Atlas SHALL possess exactly one Identity.

Identity enables uniqueness, traceability, interoperability, and long-term consistency across independent implementations.

---

## Purpose

The Identity model defines:

- Identity semantics
- Identity lifecycle
- Identity requirements
- Identity validation
- Identity interoperability

This specification intentionally does **not** define any concrete identifier format.

---

## Scope

This specification applies to every Atlas object, including:

- Entities
- Relationships
- Events
- Contracts
- Nodes
- Registries
- Runtime Components
- Future Atlas Models

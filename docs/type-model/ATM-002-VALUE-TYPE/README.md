# ATM-002 — Value Type

## Overview

A Value Type represents an immutable conceptual value within the Atlas Type Model.

Unlike Resources, Value Types do not possess an independent identity or lifecycle.

---

## Purpose

Defines immutable values used throughout Atlas.

Examples include measurements, coordinates, monetary amounts, durations, and other conceptual values.

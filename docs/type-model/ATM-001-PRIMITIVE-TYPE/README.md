# ATM-001 — Primitive Type

## Overview

Primitive Types are the smallest indivisible value types within the Atlas Type Model.

Primitive Types provide the foundation upon which all higher-order Atlas Types are constructed.

---

## Purpose

This specification establishes the abstract concept of primitive values.

It intentionally avoids defining language-specific or implementation-specific primitive types.

---

## Scope

Primitive Types are used by:

- Core Model
- Information Model
- Execution Model
- Standards

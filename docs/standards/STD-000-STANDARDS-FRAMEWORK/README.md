# STD-000 — Atlas Standards Framework

## Overview

The Atlas Standards Framework defines the structure, classification, lifecycle,
and governance of all normative artifacts within the Atlas ecosystem.

This specification establishes the common framework used by every Atlas
Standard.

---

## Purpose

This specification defines:

- Standard taxonomy
- Artifact hierarchy
- Lifecycle
- Governance relationships
- Normative language

# CTS-001 — Core Model Conformance

> This document is **Normative**.

## Purpose

Verifies that Atlas Core Model specifications are implemented correctly.

---

## Required Tests

Every implementation SHALL pass tests verifying:

- Identity uniqueness
- Version consistency
- Time representation
- State transitions
- Metadata validity
- Reference integrity
- Classification consistency
- Extension compatibility
- Capability declarations
- Constraint enforcement

---

## Result

PASS

or

FAIL

Partial conformance SHALL NOT qualify as compliant.

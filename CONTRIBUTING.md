# Welcome

Thank you for your interest in contributing to Atlas.

Atlas is a specification-driven platform. Contributions should prioritize clarity, consistency, long-term maintainability, and architectural integrity.

---

# Before You Start

Please read the following documents before contributing:

- README.md
- VISION.md
- MANIFEST.md
- ATLAS-ARC-001 Architecture Constitution
- ATLAS-ARC-002 Governance
- ATLAS-ARC-003 Repository Model

Understanding these documents is essential before proposing changes.

---

# Contribution Workflow

1. Fork the repository.
2. Create a feature branch.
3. Make focused, well-documented changes.
4. Ensure consistency with existing specifications.
5. Submit a Pull Request.

---

# Types of Contributions

Atlas welcomes contributions in several areas:

- Documentation
- Architecture
- Specifications
- Standards
- Policies
- Examples
- Tooling
- Bug Fixes

---

# Pull Request Guidelines

Every Pull Request should:

- Have a clear purpose.
- Be limited in scope.
- Include documentation updates when necessary.
- Preserve backward compatibility whenever possible.
- Follow repository conventions.

---

# Documentation Standards

All documentation must:

- Be written in English.
- Use consistent terminology.
- Follow the official document template.
- Include revision history.
- Reference related specifications where appropriate.

---

# Coding Standards

Implementation repositories should:

- Follow the relevant Atlas specifications.
- Keep changes modular.
- Avoid unnecessary dependencies.
- Prefer readability over cleverness.

---

# Review Process

All contributions are reviewed for:

- Technical accuracy
- Architectural consistency
- Documentation quality
- Long-term maintainability

Approval is required before merging.

---

# Code of Conduct

All contributors are expected to follow the project's Code of Conduct.

---

# Thank You

Every contribution helps improve Atlas for the entire community.
